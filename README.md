# TaskBoard

Tablero de tareas estilo Kanban, construido con HTML, CSS y JavaScript puro. Permite crear tareas con niveles de prioridad y moverlas entre columnas segun su estado.

## Funcionalidades

- Crear tareas con nivel de prioridad
- Columnas Kanban: Pendiente, En progreso, Hecho
- Contador de tareas

## Stack

- HTML
- CSS
- JavaScript (vanilla)

## Como correrlo

Es un proyecto estatico sin dependencias: abre `index.html` en el navegador, o publicalo con GitHub Pages (asi esta desplegado este repositorio).
